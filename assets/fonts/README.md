# Local fonts

Source Sans 3 supplies body text and controls, using regular, semibold, and bold WOFF2 files from
[Adobe’s Source Sans repository](https://github.com/adobe-fonts/source-sans/tree/release/WOFF2/TTF).
The accompanying `LICENSE.md` is the upstream SIL Open Font License.

Bricolage Grotesque supplies the wordmark and display headings. The medium (500),
Latin WOFF2 file includes the optical-size axis and was obtained through the
[Google Fonts stylesheet](https://fonts.googleapis.com/css2?family=Bricolage+Grotesque:opsz,wght@12..96,500&display=swap).
Its [upstream source](https://github.com/google/fonts/tree/main/ofl/bricolagegrotesque)
uses the SIL Open Font License, retained as `BRICOLAGE-OFL.txt`.

No external font service is called by the website.
